# PROTEINX — Image Assets Directory Guide

This directory is the central source of truth for all imagery across the PROTEINX storefront and Admin Panel.

---

## Folder Organization

| Folder | Usage | Recommended Dimensions | File Formats |
| :--- | :--- | :--- | :--- |
| public/images/products/ | Store catalog product images (tubs, bottles, boxes) | 800 x 800 px (Square, 1:1) | JPG, PNG, WEBP |
| public/images/banners/ | Homepage hero slides, promotional & category banners | 1920 x 800 px (Desktop 16:9 or 2.4:1) | PNG, JPG, WEBP |
| public/images/categories/ | Category cards (Whey, Creatine, Gainers, Pre-Workout) | 400 x 400 px | JPG, PNG, WEBP, SVG |
| public/images/lifestyle/ | Workout, gym athletes, training & fitness lifestyle | 1200 x 800 px | JPG, WEBP |
| public/images/icons/ | Brand badges, trust icons, certification seals | 120 x 120 px | SVG, PNG |

---

## Zero-Code Image Replacements

To update any image on the website directly from VS Code:

1. Locate the existing image inside public/images/products/ or public/images/banners/.
2. Replace the file with your new image **using the exact same filename** (e.g. replace whey.jpg with your new Whey protein photo named whey.jpg).
3. Refresh your browser — the storefront and admin panel will automatically display the new image across all pages (Homepage, Shop grid, Detail page, Cart, and Checkout).

No code changes or component edits are required!
